# Credit-Risk-Loan-Default-Prediction
A Machine Learning project that predicts whether a loan applicant is likely to default using Logistic Regression. The project includes data cleaning, exploratory data analysis, categorical encoding, feature scaling, model training, and evaluation using Accuracy, Classification Report, Confusion Matrix, ROC-AUC, and ROC Curve.

1. Analyzed a **45,000-row loan dataset** containing 14 customer and loan-related features.
2. Performed **data exploration and statistical analysis** using Pandas.
3. Checked the dataset for **data types and missing values**.
4. Analyzed relationships between variables using **visualizations and a correlation heatmap**.
5. Converted categorical variables into numerical values using **LabelEncoder**.
6. Selected **loan_status** as the target variable for prediction.
7. Split the data into **80% training and 20% testing** sets using stratification.
8. Applied **StandardScaler** to standardize the input features.
9. Built a **Logistic Regression model** to predict loan default status.
10. Evaluated the model using **Accuracy, Classification Report, Confusion Matrix, ROC-AUC, and ROC Curve**.
